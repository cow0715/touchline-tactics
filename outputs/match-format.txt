터치라인 · 경기 JSON 입력 형식 (version 1)

tactics-lab.html을 브라우저에서 직접 엽니다. 익명 Metrica 샘플이 파일에 포함되어 있습니다. 상단 '경기'에서 샘플을 바꿀 수 있습니다. 실제 경기 화면의 '패스 장면으로 이동'에서 각 경기의 패스 장면을 고를 수 있습니다.
경기장 화살표 또는 선택 카드를 누르면 각 선택의 결과로 이동합니다. 후속 사건을 고르고 '이 순간에서 다음 선택'을 누르면 공 소유권과 선수 위치가 이어집니다. 기존 나란히 비교는 '상세 전후 비교 및 전술 편집'에 있습니다.
• 양쪽은 같은 시작점에서 12초 동안 진행합니다. 연결되면 수신 선수가, 차단되면 공을 끊은 선수가 이어서 공격합니다.
• 경기장 아래 패스 기록을 누르면 같은 순서의 패스를 두 화면에서 각각 결과가 나온 순간으로 옮깁니다. 팀과 패스 대상은 서로 달라질 수 있습니다. 이어갈 화면에서 '여기서 재대응'을 누릅니다.
• 새 비교는 선택한 화면의 선수 위치, 공 위치, 소유권, 적용 전술을 이어받습니다. 홈·원정 명단에서 대응할 팀이나 선수를 고르고 변경한 뒤 '처음부터 재생'을 누릅니다.
• '이전 비교'를 누르면 분기하기 직전의 두 화면과 재생 위치로 돌아갑니다.
• 초보자 코칭에서 공격 또는 수비를 고르고 '이 전술로 비교'를 누르면 선수 역할과 포메이션이 적용됩니다. 추천 순서는 이 프로그램에서 계산한 패스 연결과 전진, 소유권 변화에 따릅니다.
'경기 파일 → JSON 저장'을 누르면 불러온 데이터 전체를 같은 형식으로 내려받을 수 있습니다.

영상 좌표 변환기에서 아래 형식의 UTF-8 JSON을 만든 뒤 '경기 파일 → JSON 열기'로 가져옵니다.

{
  "version": 1,
  "title": "조기축구 우측 수비 장면",
  "pitch": {"length": 105, "width": 68},
  "players": [
    {"id": "h7", "team": "home", "label": "7", "speed": 5.6, "reaction": 0.25},
    {"id": "h10", "team": "home", "label": "10"},
    {"id": "a4", "team": "away", "label": "4"}
  ],
  "frames": [
    [100, 0, 1, 10, 22, 25, 20, 20, 24, 10.3, 22],
    [101, 0.2, 1, 10.2, 22, 25.2, 20, 20.1, 24, 10.5, 22]
  ],
  "events": [
    {"frame": 100, "endFrame": 101, "type": "PASS", "team": "home", "actor": "h7", "target": "h10"}
  ]
}

• frames의 각 행은 [프레임 번호, 초, 구간 번호, 선수 1 x/y, 선수 2 x/y, …, 공 x/y]입니다.
• 좌표 단위는 미터입니다. 원점은 전술판 왼쪽 위이고, 오른쪽과 아래쪽이 양수입니다.
• 좌표는 players 순서를 따릅니다. 보이지 않는 선수·공은 [null, null]로 기록합니다. 프레임 번호는 경기 전체에서 증가하고, 시간은 각 구간 내부에서 증가해야 합니다.
• events는 비어 있어도 됩니다. PASS의 actor와 target이 있으면 장면 선택 목록에 표시됩니다. frame과 endFrame은 frames의 프레임 번호와 맞춥니다.
• speed는 모의 실험의 이동 속도(m/s, 0.1~12), reaction은 모의 실험 시작 후 움직이기까지의 지연(초, 0~3)입니다. 생략 시 5.2m/s와 0.20초를 사용합니다.
• 축구장 내 추정 위치가 원본 관측값과 섞이는 경우 변환 단계에서 따로 관리하세요. 이 버전은 보이지 않는 위치를 null로 처리합니다.
• 화면의 A팀(원)과 B팀(마름모)은 각각 JSON의 home, away입니다. 각 화면에서 현재 공격은 연두색, 수비는 파란색입니다. 공 소유가 불확실한 실제 경기 프레임에는 색을 고정하지 않습니다.
• 11명이 보이는 팀에 포메이션을 적용할 수 있습니다. 소인제나 부분 화면도 재생 및 개별 역할 변경이 가능합니다. 공격 방향은 각 구간 첫 프레임의 팀 위치로 추정하므로, 영상 클립에서 방향과 편성은 별도로 확인해야 합니다.
• 내장 Metrica 샘플은 0.2초 간격의 프레임과 이벤트 시작·종료 프레임을 포함합니다. A팀·B팀과 선수 번호는 샘플 내 식별용입니다. 실제 경기의 공 소유 팀은 패스 이벤트와 좌표를 근거로 추정합니다.
• '내 팀'에서 A팀 또는 B팀을 선택합니다. 팀은 고정되고 각 비교 화면의 공 소유권에 따라 공격·수비가 바뀝니다. 재대응을 시작하면 선택한 화면의 새 소유권을 기준으로 그 팀의 역할을 제안합니다.
• teams(선택)는 {"home":"팀 이름","away":"팀 이름"}입니다. players[].name(선택)은 실명, label은 전술판에 표시할 등번호입니다. directions(선택)는 구간 번호별로 home·away의 공격 방향(1이면 오른쪽, -1이면 왼쪽)을 지정합니다.
• frameInfo(선택)는 frames 순서에 대응하는 [소유 팀("home"/"away"/null), 소유 선수 ID 또는 null, 추정 좌표의 0부터 시작하는 선수 배열 인덱스 목록]입니다. 목록에서 선수 수와 같은 인덱스는 공입니다.
